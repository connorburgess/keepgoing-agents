What these words mean
Loop:
one goal being worked on by an agent session that keepgoing watches, wakes and holds when a person is needed.
Lane:
a child conversation a loop's agent started to work on part of the goal.
Route:
somewhere a turn can run: a model on an account at an effort level. A loop has routes in order of preference and moves down the list when one cannot continue.
Account group:
the configuration's name for routes it says share a usage allowance. The panel treats two routes as one account only when their tests read the same account.
Check:
one pass of keepgoing over a loop: look, decide, act, record.
Test:
one small real request keepgoing sends to confirm a route works before relying on it.
Hold:
a state in which keepgoing sends nothing until a person acts: paused, stopped, held for a person, or finished.
