- A stopped headless turn now always reads as crashed. A stop ends the turn wrapper's whole process group, but on Linux and macOS the wrapper could see its agent exit before its own termination arrived and record an exit code, so the same stop sometimes left a finished turn whose partial output was read as the turn's result (a completion, an error class or a session to keep). The wrapper now records no exit code once it has accepted a stop. Found as two intermittent test failures on Linux CI; fixture-tested only.
